ПРИМЕР заполненной подсказки для распознавателя (проект по геометрическому ядру САПР).
Это не рабочий файл — рабочий называется whisper-initial-prompt.ru.txt. Образец того,
как выглядит хорошая подсказка: одна фраза о контексте и затем список терминов через запятую.
Имена участников тоже можно добавить — распознаватель станет писать их правильно.
-----
Совещание команды разработки геометрического ядра САПР. Термины: R-функции Рвачёва,
FRep, функциональное представление, SDF, дистанс-функция, конвенция знака, CSG,
DAG, нод, граф, арность, агрегат, примитив, прунинг, кодогенерация, сериализация,
эвалюатор, интервальная арифметика, октодерево, рефайнмент, аффинное преобразование,
шейдер, WebGPU, WGSL, GPU, веб-клиент, темплейт, полиморфизм, константа Липшица,
рантайм, фабрика, Registry, Library, YAML, JSON, std::variant, виртуальная функция,
наследование, конструктор, указатель, облако точек.
