# Папка встреч — контекст для Claude

Это набор для локальной расшифровки аудиозаписей встреч и написания конспектов.
Записи лежат в подпапках `YYYYMMDD/`, все результаты — рядом с аудио.

## Что здесь есть

| Что | Назначение |
|---|---|
| `transcribe.py` | расшифровка (whisper.cpp, локально). Windows/macOS/Linux. `--setup` ставит whisper и модели |
| `transcribe.sh` | тот же сценарий, только для macOS (оригинал) |
| `tools/` | `chunker.py` (нарезка/склейка длинных записей), `srt_to_md.py` (абзацы с таймкодами), `qc.py` (проверка качества), `merge_parts.py` (несколько файлов одной встречи) |
| `prompts/summary-prompt.md` | правила и шаблон конспекта + блок «О проекте» |
| `prompts/whisper-initial-prompt.ru.txt` | словарь терминов для распознавателя |
| `.claude/skills/meeting-notes` | `/meeting-notes` — расшифровать новое и написать конспекты |
| `.claude/skills/new-topic` | `/new-topic` — настроить набор под новую тему |

## Правила для работы в этой папке

- Конспекты пиши строго по `prompts/summary-prompt.md`: ничего не выдумывать, у
  каждого решения/поручения/вопроса таймкод, ответственный — только если он назван
  в расшифровке явно.
- Запускай расшифровку командой `python transcribe.py` (на Windows) или
  `python3 transcribe.py` (macOS/Linux). Не устанавливай ничего без согласия пользователя.
- Не трогай аудиофайлы и не удаляй `.srt`/`.txt`/`.transcript.md` — это исходники.
- Папки `.<имя>.work/` — незавершённая расшифровка; не удалять, она продолжится при
  следующем запуске.
- Расшифровка — машинная, без разметки говорящих. Имена и термины в ней могут быть
  искажены: сомнительные места помечай, а не исправляй наугад.
