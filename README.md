# Расшифровка встреч и конспекты — локально, с Claude

Аудиозапись встречи → текстовая расшифровка с таймкодами → конспект с решениями и
поручениями. Распознавание речи работает **на вашем компьютере** (whisper.cpp): аудио
никуда не отправляется, ключи API и поминутная оплата не нужны. Конспект пишет Claude по
готовому тексту расшифровки.

Набор рассчитан на Windows (а также macOS и Linux). Инструкция ниже — для Windows и
приложения Claude для Windows.

## Коротко

```
1. Один раз:  установить Python и ffmpeg, выполнить  python transcribe.py --setup
2. Записи складывать в папки вида  20260813\  (год-месяц-день)
3. Запустить:  python transcribe.py          → рядом с аудио появится *.transcript.md
4. Открыть эту папку в Claude (вкладка Code) и набрать  /meeting-notes
   → рядом появится *.summary.md: главное, решения, поручения, открытые вопросы
```

Под новую тему набор настраивается один раз командой `/new-topic` (раздел «Настройка
под свою тему»).

## Что лежит в папке

| Файл / папка | Для чего |
|---|---|
| `transcribe.py` | расшифровка записей. Windows, macOS, Linux. `--setup` скачивает всё нужное |
| `prompts/summary-prompt.md` | правила и шаблон конспекта. Блок «О проекте» — то, что меняется под вашу тему |
| `prompts/whisper-initial-prompt.ru.txt` | словарь терминов и имён для распознавателя — тоже под вашу тему |
| `prompts/whisper-initial-prompt.example.txt` | образец заполненного словаря |
| `.claude/skills/meeting-notes/` | команда `/meeting-notes` для Claude: расшифровать новое и написать конспекты |
| `.claude/skills/new-topic/` | команда `/new-topic`: настроить набор под новый проект в диалоге |
| `CLAUDE.md` | контекст для Claude — он читает его автоматически при открытии папки |
| `tools/` | служебные скрипты: нарезка длинных записей, абзацы с таймкодами, проверка качества, склейка частей |
| `bin/` | сюда `--setup` складывает whisper.cpp |
| `transcribe.sh`, `tools/merge_parts.sh` | оригиналы для macOS; на Windows не нужны |

Записи кладутся **в эту же папку**, по подпапкам с датой:

```
<эта папка>\
  20260813\
    Встреча по проекту 13.08.2026.m4a
  20260901\
    kickoff.m4a
    kickoff — продолжение.m4a
```

Одна папка на день, имя `ГГГГММДД`, внутри сколько угодно записей любого формата
(`m4a`, `mp3`, `wav`, `mp4`, `mov`, `flac`, `ogg`, `opus`, записи диктофона телефона…).
Все результаты появляются рядом с аудио.

## Установка на Windows (один раз)

Нужны: Windows 10/11 (64-бит), ~5 ГБ свободного места, интернет на время установки.
Права администратора не требуются.

### 1. Python

Откройте PowerShell (Пуск → наберите «PowerShell») и выполните:

```powershell
winget install Python.Python.3.12
```

Либо скачайте установщик с https://www.python.org/downloads/windows/ и при установке
обязательно поставьте галочку **«Add python.exe to PATH»**.

### 2. ffmpeg (чтение аудиоформатов)

```powershell
winget install Gyan.FFmpeg
```

Если `winget` не найден — скачайте сборку «release essentials» с
https://www.gyan.dev/ffmpeg/builds/, распакуйте и скопируйте `ffmpeg.exe` и
`ffprobe.exe` из её папки `bin` в папку `bin\` этого набора.

### 3. Закройте PowerShell и откройте заново

После установки программы появляются в PATH только в **новом** окне терминала.
Проверьте:

```powershell
python --version
ffmpeg -version
```

Обе команды должны что-то напечатать, а не «не является командой».

### 4. whisper.cpp и модель распознавания

В PowerShell перейдите в папку набора и запустите установку:

```powershell
cd "C:\путь\к\этой\папке"
python transcribe.py --setup
```

Если в компьютере видеокарта NVIDIA (GeForce / RTX) — вместо этого:

```powershell
python transcribe.py --setup-cuda
```

Скрипт скачает:

- whisper.cpp (`whisper-cli.exe`, ~10 МБ, или ~400 МБ для версии CUDA) в папку `bin\`;
- модель распознавания `large-v3` (**3,1 ГБ**) и маленькую модель детектора речи — в
  `C:\Users\<вы>\.cache\whisper-cpp\models\`. Это долго; зависит от скорости интернета.

Если автоматическое скачивание не удалось — инструкция по ручной установке в `bin\README.md`.
Модели вручную берутся отсюда: https://huggingface.co/ggerganov/whisper.cpp/tree/main
(файл `ggml-large-v3.bin`) и https://huggingface.co/ggml-org/whisper-vad/tree/main
(файл `ggml-silero-v5.1.2.bin`); положите их в папку моделей выше.

> Windows может показать предупреждение SmartScreen / Defender при первом запуске
> `whisper-cli.exe` — это неподписанная сборка с GitHub проекта whisper.cpp. Разрешите
> запуск («Подробнее» → «Выполнить в любом случае»).

### 5. Проверка

```powershell
python transcribe.py --list
```

Должно напечатать список записей, которые ещё не расшифрованы (или «no audio found»,
если папок с датами ещё нет — это нормально).

## Повседневная работа

### Расшифровать

1. Скопируйте запись в папку `ГГГГММДД\` (создайте, если нет).
2. В PowerShell в папке набора:

```powershell
python transcribe.py
```

Скрипт находит все записи без расшифровки и обрабатывает их; готовые пропускает, так
что запускать можно сколько угодно раз. Для каждой записи рядом появятся:

| Файл | Что это |
|---|---|
| `<имя>.transcript.md` | **то, что читать** — абзацы с таймкодами |
| `<имя>.txt` | чистый текст без таймкодов — для поиска или вставки куда-то ещё |
| `<имя>.srt` | субтитры; открыв аудио рядом, можно прыгнуть в нужное место |
| `<имя>.transcribe.log` | служебный вывод whisper; нужен, только если что-то сломалось |
| `<имя>.summary.md` | конспект — появляется после `/meeting-notes` |

**Сколько ждать.** На обычном процессоре (без видеокарты NVIDIA) модель `large-v3`
работает медленно: ориентируйтесь на **время, сравнимое с длительностью записи или
больше** — двухчасовая встреча может считаться 2–4 часа. Запустите и занимайтесь
другим; закрыть ноутбук можно — длинные записи режутся на ~15-минутные куски, и при
следующем запуске работа продолжится с первого недоделанного куска.

Если ждать так долго не хочется:

```powershell
python transcribe.py --model large-v3-turbo        # примерно в 3 раза быстрее, чуть хуже на именах и терминах
python transcribe.py --model large-v3-turbo-q5_0   # ещё быстрее и 0,6 ГБ вместо 1,6; качество почти то же
```

Попробуйте на одной короткой записи, сравните с `large-v3` и, если устраивает,
сделайте выбор постоянным: в PowerShell `setx WHISPER_MODEL large-v3-turbo` (действует
в новых окнах). С видеокартой NVIDIA и установкой `--setup-cuda` даже `large-v3` работает
в несколько раз быстрее реального времени.

### Написать конспект — с приложением Claude для Windows

Нужна подписка Claude Pro, Max, Team или Enterprise (Claude Code в бесплатный план не
входит). Приложение: https://claude.com/download.

1. Откройте приложение Claude. Сверху три вкладки: **Chat**, **Cowork**, **Code**.
   Выберите **Code**.
2. В выборе окружения укажите **Local**, нажмите **Select folder** и выберите папку
   этого набора (ту, где лежит `transcribe.py`).
3. Режим разрешений (внизу поля ввода) — для начала **Manual** или **Accept edits**:
   Claude будет спрашивать перед запуском команд и записью файлов.
4. В поле ввода наберите:

```
/meeting-notes
```

   Если при наборе `/` команды `meeting-notes` нет в списке — напишите обычным текстом:
   «Выполни инструкцию из `.claude/skills/meeting-notes/SKILL.md`». Результат тот же.

Claude сам запустит `python transcribe.py` для новых записей (это может занять долго —
см. выше; можно заранее расшифровать из PowerShell, тогда этот шаг мгновенный),
прочитает каждую расшифровку целиком и запишет `<имя>.summary.md` рядом с ней: главное,
решения, таблица поручений с ответственными и таймкодами, открытые вопросы, ход
обсуждения.

Варианты:

```
/meeting-notes 20260813              конспекты только для этой папки
/meeting-notes 20260813 --force      переписать уже существующие конспекты
```

Вкладка **Cowork** скиллы из папки не читает — для этого набора пользуйтесь вкладкой **Code**.

### Вариант без вкладки Code: Claude Code в терминале

То же самое из PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex        # установка, один раз
cd "C:\путь\к\этой\папке"
claude
```

и внутри — `/meeting-notes`. Для работы `Bash`-команд Claude Code рекомендует
установить Git for Windows (https://git-scm.com/downloads/win); без него используется
PowerShell, скрипты набора работают и так. Если установка ругается «running scripts is
disabled on this system», выполните один раз
`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`.

### Вариант совсем без Claude Code: обычный чат

Откройте в приложении Claude вкладку **Chat**, прикрепите файл `<имя>.transcript.md`,
а текстом сообщения вставьте содержимое `prompts\summary-prompt.md`. Получите тот же
конспект, но сохранять его в файл придётся вручную. Удобно для одной-двух встреч.

## Настройка под свою тему

Набор знает о вашем проекте ровно то, что записано в двух файлах. Пока они не
заполнены, расшифровка будет коверкать имена и термины, а конспект — не понимать, что
важно.

**Проще всего** — во вкладке Code набрать:

```
/new-topic
```

Claude задаст несколько вопросов (о чём встречи, кто участвует, какие термины и
названия звучат постоянно, что всегда надо отслеживать) и заполнит оба файла.

**Вручную:**

1. `prompts\whisper-initial-prompt.ru.txt` — одна фраза о контексте и список
   терминов и имён через запятую, в том написании, в каком они должны появляться в
   тексте. Без заголовков и комментариев: весь файл целиком отдаётся распознавателю
   как подсказка. Не длиннее абзаца — используется лишь около 200 первых токенов.
   Образец — `whisper-initial-prompt.example.txt`.
2. `prompts\summary-prompt.md` — замените текст под заголовком «## О проекте»
   (2–6 строк: команда, предмет, участники с ролями, что обязательно фиксировать).
   Остальное не трогайте.
3. По желанию — две строки о проекте в `CLAUDE.md`, раздел «О проекте».

Уже расшифрованные записи новый словарь не затронет. Чтобы переделать одну:
`python transcribe.py --force 20260813`.

## Одна встреча в нескольких файлах

Если диктофон ставили на паузу или меняли батарейку и встреча оказалась в двух-трёх
файлах, расшифруйте их как обычно, затем склейте в один комплект:

```powershell
python tools\merge_parts.py "Встреча 20.08.2026" "20260820\часть1.m4a" "20260820\часть2.m4a"
```

Рядом с первой частью появятся `Встреча 20.08.2026.srt / .txt / .transcript.md` на
единой шкале времени (таймкоды второй части сдвинуты на длину первой; в шапке написано,
где начинается каждая часть). Конспект пишите по склеенному файлу.

## Параметры

| Команда | Что делает |
|---|---|
| `python transcribe.py 20260813` | только эта папка (можно указать и один файл) |
| `python transcribe.py --list` | показать, что будет обработано, ничего не делать |
| `python transcribe.py --force` | переделать уже готовые расшифровки |
| `python transcribe.py --lang en` | язык записи (по умолчанию `ru`; `auto` — определить самому) |
| `python transcribe.py --model large-v3-turbo` | другая модель (см. таблицу ниже) |
| `python transcribe.py --threads 8` | число потоков процессора (по умолчанию все ядра) |
| `python transcribe.py --no-vad` | не пропускать тишину |
| `python transcribe.py --no-prompt` | не использовать словарь терминов |
| `python transcribe.py --chunk-minutes 10` | короче куски — точнее возобновление после прерывания |
| `python transcribe.py --no-chunks` | одним проходом; без возобновления |
| `python transcribe.py --keep-work` | не удалять нарезанное аудио после успеха |
| `python transcribe.py --whisper-cli "C:\...\whisper-cli.exe"` | явный путь к whisper, если лежит не в `bin\` |

Те же настройки через переменные окружения: `WHISPER_MODEL`, `WHISPER_LANG`,
`WHISPER_MODEL_DIR`, `WHISPER_CLI`.

### Модели

| Модель | Размер | Скорость | Когда |
|---|---|---|---|
| `large-v3` *(по умолчанию)* | 3,1 ГБ | медленно на CPU | русская речь, имена, термины — самый точный вариант |
| `large-v3-turbo` | 1,6 ГБ | ~3× быстрее | хороший компромисс для процессора без видеокарты |
| `large-v3-turbo-q5_0` | 0,6 ГБ | ещё быстрее | тот же turbo, сжатый; почти без потери качества |
| `medium` | 1,5 ГБ | быстро | короткая чистая запись одного человека |

Любая модель скачивается автоматически при первом использовании.

### Детектор речи (VAD)

Включён по умолчанию. Находит речь и пропускает тишину — это быстрее и, главное, мешает
распознавателю выдумывать текст в долгих паузах (его любимая ошибка). Таймкоды
пересчитываются обратно в исходную запись и остаются точными.

### Почему расшифровка не «зациклится»

Худшая ошибка whisper — петля повторов: он выдаёт одну правдоподобную фразу, затем, так
как опирается на только что написанный текст, выдаёт её снова и не может выбраться.
В одном реальном случае он застрял на 14-й минуте и написал одну и ту же фразу 1339 раз,
проглотив полчаса обсуждения. От этого защищают три вещи:

1. ключ `-mc 0` — каждое окно декодируется без предыдущего текста, повтор не может
   себя подкреплять. Это главное лекарство;
2. нарезка на куски — петля, если и начнётся, умрёт на границе куска, через 15 минут;
3. `tools/srt_to_md.py` сворачивает уцелевшие повторы и помечает их в расшифровке, чтобы
   это было видно, а не тихо раздувало текст.

Если в расшифровке одна фраза повторена много раз — это оно: аудио там не распознано.
Сверьтесь с записью по таймкоду.

## Если что-то выглядит неправильно

После каждой расшифровки запускается проверка (`tools/qc.py`) и печатает `qc: OK` либо
`qc: WARNING`. **Предупреждение означает: послушайте аудио в этом месте, прежде чем
верить тексту.** Проверку можно запустить и отдельно:

```powershell
python tools\qc.py "20260813\Встреча 13.08.2026.srt" --duration 9906
```

| Сообщение | Что значит | Что делать |
|---|---|---|
| `is empty (0 bytes) — an interrupted copy` | копирование файла не завершилось | скопировать запись заново, запустить ещё раз |
| `qc: WARNING — recogniser loop` | одна фраза повторена много раз; этот отрезок **не распознан** | не должно случаться (`-mc 0`); если случилось — `--force` на этот файл |
| `qc: WARNING — gap` | минуты без распознанной речи | нормально, если был перерыв; иначе проверить аудио |
| `qc: WARNING — coverage` | расшифровка кончается раньше записи | запустить ещё раз; прерванная расшифровка продолжится |
| `qc: WARNING — density` | слов в минуту обнаруженной речи заметно меньше обычного | неверный язык (`--lang`) или сбой декодера: проверить самые тихие места |
| `qc: OK … speech 67% of audio` | справочно: доля речи в записи | ничего; демонстрации и работа у доски дают низкую долю |
| `date in file name (…) ≠ folder (…)` | дата в имени файла и в имени папки не совпадают | опечатка в одной из них; исправить **до** того, как файлы результатов её унаследуют |

Типичные проблемы установки:

| Симптом | Причина / решение |
|---|---|
| `python` не является командой | Python не в PATH: переустановить с галочкой «Add to PATH», либо вызывать `py transcribe.py` |
| `ffmpeg not found` сразу после установки | откройте новое окно PowerShell |
| `whisper-cli not found` | выполните `python transcribe.py --setup` или положите распакованный whisper в `bin\` (см. `bin\README.md`) |
| `could not download …` | нет доступа к GitHub / Hugging Face (корпоративная сеть, VPN): скачайте файлы вручную по ссылкам в разделе установки |
| всё очень медленно | это нормально для `large-v3` на процессоре; возьмите `--model large-v3-turbo` или сборку CUDA |
| кракозябры вместо русских букв в консоли | используйте Windows Terminal вместо старой консоли; файлы при этом записаны правильно (UTF-8) |
| `.<имя>.work` папка осталась после прерывания | так и задумано — при следующем запуске работа продолжится; удалится сама после успеха |

## Чего набор не делает

**Не различает говорящих.** Расшифровка — один сплошной поток без указания, кто
говорит. whisper.cpp умеет разделять голоса только по стереоканалам, а диктофон в
комнате пишет всех в оба канала. Если метки говорящих станут действительно нужны —
это отдельная работа (облачные сервисы с диаризацией либо локально `pyannote`).

**Машинный текст, и это заметно.** Имена, аббревиатуры и обрывки фраз распознаются
с ошибками, особенно когда говорят одновременно. Таймкоды в `.transcript.md` нужны,
чтобы любое важное место можно было проверить по аудио за секунды. Конспект
сгенерирован по этому тексту и **не проверен участником встречи** — считайте его
черновиком, пока его не прочитал тот, кто был в комнате.

## macOS

На Mac всё работает так же через `python3 transcribe.py` (ffmpeg и whisper:
